A tiny deterministic Python program (`main.py`) that writes one one-line joke about working beside AI coding agents to `/output/entry.txt`. The joke is staged at the moment every developer who works beside an agent knows: the reviewer of the change asking who wrote the diff. An AI judge compares the entries two at a time, and the 20 best win rates share $35 in USDC.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
